技術挑戰TECHNICAL CHALLENGES
Challenge

Carousel 在不同螢幕尺寸下容易錯位，卡片之間出現間距不一致的問題。

Solution

改用 clamp() 搭配 CSS transform 重新計算卡片寬度與位移量，不依賴固定像素。

Result

桌機與手機皆穩定顯示，無需媒體查詢即可自適應。

Challenge

分層透明 webp 圖片在不同瀏覽器的渲染順序與合成效果有差異。

Solution

統一使用 position:absolute + z-index 管理每一圖層，確保合成行為一致。

Result

跨瀏覽器場景渲染一致，吊燈・人物・螢幕各層正確疊合。

Challenge

純靜態 HTML 無框架，難以在多頁面間共享 Sidebar、游標等元件。

Solution

每頁內嵌完整 CSS + JS，維持一個 .html 一個完整世界的原則。

Result

部署零配置，任意靜態空間皆可上線，維護成本低。

反思與回顧REFLECTION
做這個網站
讓我明白「體驗」
比「展示」更重要

從一開始只是想要一個放作品的地方，到後來開始思考「訪客的第一秒會感受到什麼」——這個轉變讓整個設計方向完全改變了。

學到了什麼
純靜態 HTML 的極限與可能性，以及「少即是多」的互動設計哲學。不需要框架也能做出讓人印象深刻的體驗。
未來想優化的方向
考慮升級至 Vite + React 以支援元件共享；加入更多跨頁面的連貫敘事，讓整個網站感覺像一個完整的故事。
最滿意的部分
聚光燈系統。簡單的 Canvas radial-gradient 跟隨滑鼠，卻能製造出強烈的「探索感」，是成本最低、回報最高的設計決策。
